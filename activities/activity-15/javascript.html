Variables — storing information

A variable is like a labelled box that holds a value. Use let when the value might change later, and const when it should stay the same. Change the name variable to your own name and run it!

let name = "Alex";       // can change later
const greeting = "Hello"; // stays the same

console.log(greeting + ", " + name + "!");

Template literals — a cleaner way to combine text

Template literals use backticks ( ` ) instead of quotes, and let you drop variables right into a string using ${}. This is much easier to read than joining lots of pieces with +. Update the name and age, then run it.

let name = "Alex";
let age  = 14;

// Note the backticks ` ` around the string
console.log(`My name is ${name} and I am ${age} years old.`);
